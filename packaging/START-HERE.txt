Lillia First Person 0.1.28 - Windows x64 fresh-install bundle
English / 日本語 / 简体中文 / 繁體中文

ENGLISH
1. Save and exit the game. This bundle is intended for a fresh game 1.1 installation without an existing mod loader.
2. Extract ALL contents directly beside NoviceSuccubusLillia.exe (not into its Data folder or an extra nested folder).
3. Start the game normally. First launch needs Internet access to download Unity base libraries and generate interop files. It may take several minutes; do not repeatedly launch the game.
4. First person is enabled by default. F8 toggles first/third person; F9 toggles hair visibility.
The three recommended ClipLimits entries are already configured (3 degrees left/right, 2 up/down). Other animations use 75 left/right, 75 up, 85 down. If NPCs block an event view, press F8.
Already using BepInEx or other mods? Use the plugin-only release instead; do not overwrite your loader, winhttp.dll, or configuration with this fresh-install bundle. Existing settings would be overwritten by extraction.
Troubleshooting: BepInEx/LogOutput.log and BepInEx/FirstPersonTest.log. No console window is expected. Documentation: LilliaFirstPerson-Docs/README.md.
Remove only BepInEx/plugins/FirstPersonTest.dll to uninstall this plugin. Do not delete shared loader files used by other mods.
The bundle has been statically checked; its first-run process has not been retested on a clean game installation. It contains the same loader and plugin binaries as the tested setup. No game files or generated interop/cache files are included.

简体中文

2. 将全部内容解压到 NoviceSuccubusLillia.exe 所在目录，不要放进 Data 文件夹或额外套一层文件夹。
3. 正常启动游戏。首次启动需要联网下载 Unity 基础库并生成 interop，可能需要等待数分钟，请勿反复启动。
4. 默认开启第一人称。F8 切换第一／第三人称，F9 隐藏／显示头发。
三个推荐动作的 ClipLimits 已配置好（左右各 3°、上下各 2°）；其他动作使用左右各 75°、上 75°、下 85°。演出被 NPC 挡住时按 F8。
已安装 BepInEx 或其他 MOD 的玩家请使用普通插件包，不要用本包覆盖原有加载器、winhttp.dll 或配置；直接覆盖解压会替换已有设置。
排错日志：BepInEx/LogOutput.log、BepInEx/FirstPersonTest.log。不弹日志控制台属于正常设置。说明：LilliaFirstPerson-Docs/README.zh-CN.md。
卸载插件只需删除 BepInEx/plugins/FirstPersonTest.dll，不要删除其他 MOD 共用的加载器。
本包已完成静态检查，未在干净游戏上重新实测首次启动流程。加载器和插件与已测试环境一致，不包含游戏文件、已生成的 interop 或缓存。
