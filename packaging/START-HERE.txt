Lillia First Person 0.1.28 - Windows x64 fresh-install bundle

ENGLISH
1. Save and exit the game. This bundle is intended for a fresh game 1.1 installation without an existing mod loader.
2. Extract ALL contents directly beside NoviceSuccubusLillia.exe (not into its Data folder or an extra nested folder).
3. Start the game normally. First launch needs Internet access to download Unity base libraries and generate interop files. It may take several minutes; do not repeatedly launch the game.
4. First person is enabled by default. F8 toggles first/third person; F9 toggles hair visibility.
The four recommended ClipLimits entries are already configured (3 degrees left/right, 2 up/down). Other animations use 75 left/right, 75 up, 85 down. If NPCs block an event view, press F8.
Already using BepInEx or other mods? Use the plugin-only release instead; do not overwrite your loader, winhttp.dll, or configuration with this fresh-install bundle. Existing settings would be overwritten by extraction.
Troubleshooting: BepInEx/LogOutput.log and BepInEx/FirstPersonTest.log. No console window is expected. Documentation: LilliaFirstPerson-Docs/README.md.
Remove only BepInEx/plugins/FirstPersonTest.dll to uninstall this plugin. Do not delete shared loader files used by other mods.
First-launch dependency generation and plugin loading completed in the clean test copy. The game loaded from a short path, and first-person event rendering was confirmed in the logs. The newly added Gsun limit matches the catalog and runtime clip name; its restricted movement still needs in-game confirmation. This is not exhaustive gameplay validation.
Game folder path: Use a short folder such as C:\Games\Lillia. A deeply nested test folder failed with Character content could not be loaded and A local absolute bundle path is required, even with BepInEx disabled; the same files loaded successfully from a shorter folder. If this happens, exit the game and move the entire game folder to a shorter path. The exact maximum supported path length is not established.

简体中文
1. 保存并退出游戏。本包适用于游戏 1.1 版本，供尚未安装 BepInEx 加载器的玩家使用。
2. 将全部内容解压到 NoviceSuccubusLillia.exe 所在目录，不要放进 Data 文件夹或额外套一层文件夹。
3. 正常启动游戏。首次启动需要联网下载 Unity 基础库并生成 interop，可能需要等待数分钟，请勿反复启动。
4. 默认开启第一人称。F8 切换第一／第三人称，F9 隐藏／显示头发。
四个推荐动作的 ClipLimits 已配置好（左右各 3°、上下各 2°）；其他动作使用左右各 75°、上 75°、下 85°。演出被 NPC 挡住时按 F8。
已安装 BepInEx 或其他 MOD 的玩家请使用普通插件包，不要用本包覆盖原有加载器、winhttp.dll 或配置；直接覆盖解压会替换已有设置。
排错日志：BepInEx/LogOutput.log、BepInEx/FirstPersonTest.log。不弹日志控制台属于正常设置。说明：LilliaFirstPerson-Docs/README.zh-CN.md。
卸载插件只需删除 BepInEx/plugins/FirstPersonTest.dll，不要删除其他 MOD 共用的加载器。
干净测试副本已完成首次依赖生成和插件加载；短路径下成功进入游戏，日志确认了第一人称演出渲染。新增 Gsun 限制已与资源目录及运行时动作名核对，其受限转动范围仍待游戏内确认；尚未穷尽所有场景测试。
游戏目录路径： 建议使用 C:\Games\Lillia 等短路径。测试中，目录层级过深时，即使关闭 BepInEx 也会出现 Character content could not be loaded / A local absolute bundle path is required；同一份文件换到短路径后成功加载。遇到此错误，请退出游戏，将整个游戏文件夹移到短路径。尚未确定游戏支持的精确路径长度上限。

繁體中文
1. 存檔並結束遊戲。本包適用於遊戲 1.1 版本，供尚未安裝 BepInEx 載入器的玩家使用。
2. 將全部內容解壓縮至 NoviceSuccubusLillia.exe 所在目錄，不要放入 Data 資料夾或多套一層資料夾。
3. 正常啟動遊戲。首次啟動需連網下載 Unity 基礎函式庫並產生 interop，可能需等待數分鐘，請勿重複啟動。
4. 預設開啟第一人稱。F8 切換第一／第三人稱，F9 隱藏／顯示頭髮。
四個推薦動作的 ClipLimits 已設定好（左右各 3°、上下各 2°）；其他動作為左右各 75°、上 75°、下 85°。演出被 NPC 遮住時按 F8。
已安裝 BepInEx 或其他 MOD 者請使用一般外掛包，不要覆蓋原有載入器、winhttp.dll 或設定；直接覆蓋解壓縮會取代既有設定。
排錯日誌：BepInEx/LogOutput.log、BepInEx/FirstPersonTest.log。不顯示主控台是正常設定。說明：LilliaFirstPerson-Docs/README.zh-TW.md。
移除外掛只需刪除 BepInEx/plugins/FirstPersonTest.dll，不要刪除其他 MOD 共用的載入器。
乾淨測試副本已完成首次相依項目產生和外掛載入；短路徑下成功進入遊戲，日誌確認了一人稱演出繪製。新增 Gsun 限制已與資源目錄及執行時動作名稱核對，其受限轉動範圍仍待遊戲內確認；尚未完整測試所有場景。
遊戲目錄路徑： 建議使用 C:\Games\Lillia 等短路徑。測試時，目錄層級過深即使關閉 BepInEx，仍出現 Character content could not be loaded / A local absolute bundle path is required；相同檔案改放短路徑後成功載入。遇到此錯誤，請結束遊戲，將整個遊戲資料夾移至短路徑。目前尚未確定遊戲支援的精確路徑長度上限。
