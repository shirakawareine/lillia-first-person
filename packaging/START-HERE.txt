## Installation and troubleshooting

### Choose by installed components

Tested game versions: **1.1 and 1.2**, Windows x64. The bundle contains BepInEx **6 be.788 for IL2CPP x64**; Mono, x86 and BepInEx 5 packages are not substitutes. It does not include the game.

- **BepInEx not installed:** download `FirstPersonTest-0.1.28-bundle-win-x64.zip` from [Releases](https://github.com/shirakawareine/lillia-first-person/releases/tag/v0.1.28).
- **Compatible BepInEx already installed:** download `FirstPersonTest-0.1.28-release.zip` or `FirstPersonTest.dll`, and keep the existing loader and settings.
- **Source code:** `FirstPersonTest-0.1.28-source.zip` is for building the plugin, not installing it. GitHub's automatic source archives are not installation packages either.

Check the game folder for `BepInEx` and `winhttp.dll`. Their presence indicates an existing loader or modification that needs checking; do not blindly overwrite it. Confirm the BepInEx version and IL2CPP runtime in `BepInEx/LogOutput.log` when available.

### Bundle installation (BepInEx not installed)

1. Save and exit the game. Back up saves and any existing configuration before changing the installation.
2. Use a short game path such as `C:\Games\Lillia`. Move the **whole game folder**, not just the EXE, if needed. A deeply nested test copy failed to load character content even without BepInEx; the same files worked at a shorter path. The exact path-length threshold is unknown.
3. Extract **all contents** of the bundle beside `NoviceSuccubusLillia.exe`. Do not run the game inside an archive, extract into the Data folder, or leave an extra bundle folder between the EXE and the loader files.
4. Compare the layout below. The EXE and Data folder are supplied by your game installation; the bundle adds the loader, runtime, plugin and configuration.

```text
C:\Games\Lillia\
  NoviceSuccubusLillia.exe
  NoviceSuccubusLillia_Data\
  winhttp.dll
  doorstop_config.ini
  dotnet\
  BepInEx\
    core\
    plugins\FirstPersonTest.dll
    config\BepInEx.cfg
    config\local.lillia.firstpersontest.cfg
```

5. Launch the usual game EXE. First launch needs Internet access to download Unity base libraries and time to generate `BepInEx/interop`; several minutes may be needed. Do not launch multiple copies while waiting. No log console window is expected.
6. Enter normal gameplay. First person starts enabled. With the game focused, test **F8** to switch views and **F9** to hide/show hair. The plugin log should contain `Loaded v0.1.28`. Successful loading alone does not verify every gameplay feature.

### Plugin installation or update (BepInEx installed)

1. Save and exit. Back up the old DLL and `BepInEx/config/local.lillia.firstpersontest.cfg` outside the `plugins` folder.
2. Replace `BepInEx/plugins/FirstPersonTest.dll`. Keep only one copy, including in subfolders; do not leave backup DLLs there. Keep your existing loader and configuration.
3. On first plugin-only installation, launch once to generate the configuration, then exit. A newly generated `ClipLimits` is empty; the bundle already contains four presets.
4. Updating the DLL does **not** merge new presets into existing settings. In `[EventView]`, merge the four-entry example in the bundled README into the existing `ClipLimits` line, keeping custom entries. Use one entry per exact clip name and keep the whole value on one line. The added Gsun entry is `Fellatio_Female(Gsun)_Loop|3|2|2`.
5. Save and restart. Configuration is read at startup. The bundle revision changes presets and documentation, not the 0.1.28 DLL.

### Troubleshooting

| Symptom | Check first |
| --- | --- |
| No first-person view or no F8 response | Enter gameplay, focus the game window, check the folder layout and duplicate DLLs. Then check loader and plugin logs for a successful load or an error. |
| First launch appears stuck | Check whether `BepInEx/LogOutput.log` is still progressing through downloads or interop generation. If it reports a download failure, check connectivity and the specific error before retrying; do not repeatedly start extra copies. |
| `Character content could not be loaded` | Look for `A local absolute bundle path is required` in the Unity player log. If present, exit and move the entire game to a shorter path. The message alone does not prove a path issue; preserve logs if it persists. |
| Event view still has a wide range | Check the exact `Event view: clip=...` name, the matching ClipLimits entry and whether you restarted. Names are case-sensitive; unknown clips use general limits. |
| Hair or an NPC blocks the view | F9 toggles hair; F8 returns to third person during obstructed scenes. |

Loader log: `BepInEx/LogOutput.log`. Plugin log: `BepInEx/FirstPersonTest.log`. Unity log: `%USERPROFILE%\AppData\LocalLow\PaconeSoft\Novice Succubus Lillia\Player.log`. Preserve relevant logs before another launch; do not clear saves or caches as a routine installation step.

To temporarily disable first person, press F8. To uninstall the plugin, exit and remove only `BepInEx/plugins/FirstPersonTest.dll`; keep shared loader files needed by other mods. To roll back, restore the backed-up DLL and configuration. `SHA256SUMS.txt` provides download checksums.

The Gsun clip restriction (3° left/right, 2° up/down) has passed in-game testing, as confirmed by the tester. This does not imply exhaustive testing of all clips.

**Game 1.2 compatibility (2026-10-23):** The published v0.1.28 bundle was downloaded from GitHub Releases and installed on game version 1.2. After first-launch initialization, the user reported that it ran without apparent issues. No plugin changes were needed for this test. This is user-reported runtime compatibility, not exhaustive validation of every scene, animation or new game mechanic. Earlier game 1.1 testing remains documented below.

## 安装步骤与常见问题

### 按已安装的组件选择下载

适用环境为游戏 **1.1／1.2 版本**、Windows x64。整合包使用 **BepInEx 6 be.788 IL2CPP x64**；Mono、x86 和 BepInEx 5 版本不能替代。不包含游戏本体。

- **未安装 BepInEx：** 从 [Releases](https://github.com/shirakawareine/lillia-first-person/releases/tag/v0.1.28) 下载 `FirstPersonTest-0.1.28-bundle-win-x64.zip`。
- **已安装兼容的 BepInEx：** 下载 `FirstPersonTest-0.1.28-release.zip` 或 `FirstPersonTest.dll`，保留已有加载器与配置。
- **源码：** `FirstPersonTest-0.1.28-source.zip` 用于编译插件，不是安装包；GitHub 自动生成的源码压缩包也不是安装包。

先查看游戏目录是否已有 `BepInEx` 文件夹或 `winhttp.dll`。存在这些文件说明可能已安装加载器或其他修改，应先核对，不能直接覆盖；可在已有的 `BepInEx/LogOutput.log` 中确认 BepInEx 版本和 IL2CPP 运行环境。

### 整合包安装（未安装 BepInEx）

1. 保存并退出游戏。修改安装目录前，备份存档和已有配置。
2. 建议使用 `C:\Games\Lillia` 等短路径，需要调整时移动**整个游戏文件夹**，不要只移动 EXE。测试中深层目录即使未启用 BepInEx 也无法加载角色，相同文件改放短路径后成功；尚未确定精确的长度上限。
3. 将整合包的**全部内容**解压到 `NoviceSuccubusLillia.exe` 旁边。不要在压缩包内启动，不要解压到 Data 文件夹，也不要让加载器文件与 EXE 之间多套一层整合包文件夹。
4. 对照下列目录。EXE 和 Data 文件夹来自游戏本体；整合包提供加载器、运行时、插件与配置。

```text
C:\Games\Lillia\
  NoviceSuccubusLillia.exe
  NoviceSuccubusLillia_Data\
  winhttp.dll
  doorstop_config.ini
  dotnet\
  BepInEx\
    core\
    plugins\FirstPersonTest.dll
    config\BepInEx.cfg
    config\local.lillia.firstpersontest.cfg
```

5. 启动平时使用的游戏 EXE。首次需要联网下载 Unity 基础库并生成 `BepInEx/interop`，可能需要数分钟。等待时不要重复启动多个游戏进程。没有弹出日志控制台属于正常设置。
6. 进入正式游戏后，第一人称默认开启。在游戏窗口处于前台时，测试 **F8** 切换视角、**F9** 隐藏／显示头发。插件日志应出现 `Loaded v0.1.28`；加载成功不等于所有游戏功能都已经验证。

### 插件安装与更新（已安装 BepInEx）

1. 保存并退出。将旧 DLL 和 `BepInEx/config/local.lillia.firstpersontest.cfg` 备份到 `plugins` 文件夹以外的位置。
2. 替换 `BepInEx/plugins/FirstPersonTest.dll`。包括子文件夹在内只保留一份插件，备份 DLL 不要留在其中。保留已有加载器和配置。
3. 首次单独安装插件时，先运行一次生成配置，再退出。新生成的 `ClipLimits` 为空；整合包则已带四条预设。
4. 替换 DLL **不会**自动合并新增预设。在 `[EventView]` 中，把包内 README 的四条示例合并到现有的 `ClipLimits` 一行，保留自定义条目。每个精确动作名只出现一次，整个值保持一行。本次新增的是 `Fellatio_Female(Gsun)_Loop|3|2|2`。
5. 保存并重启游戏，配置在启动时读取。本次整合包修订只更新预设与说明，0.1.28 DLL 未改变。

## インストール手順とトラブル対処

### 導入済みの構成に応じたダウンロード

対象はゲーム **バージョン 1.1／1.2**、Windows x64 です。同梱ローダーは **BepInEx 6 be.788 IL2CPP x64** です。Mono、x86、BepInEx 5 版で代用しないでください。ゲーム本体は含まれません。

- **BepInEx 未導入：** [Releases](https://github.com/shirakawareine/lillia-first-person/releases/tag/v0.1.28) から `FirstPersonTest-0.1.28-bundle-win-x64.zip` をダウンロードします。
- **対応する BepInEx を導入済み：** `FirstPersonTest-0.1.28-release.zip` または `FirstPersonTest.dll` を使用し、既存ローダーと設定を残します。
- **ソース：** `FirstPersonTest-0.1.28-source.zip` はビルド用であり、インストール用ではありません。GitHub 自動生成のソースアーカイブも同様です。

ゲームフォルダーに `BepInEx` や `winhttp.dll` があるか確認してください。既存ローダーや別の変更がある可能性があるため、確認せず上書きしないでください。既存の `BepInEx/LogOutput.log` があれば、BepInEx バージョンと IL2CPP 実行環境を確認できます。

### 同梱セットの導入（BepInEx 未導入）

1. セーブしてゲームを終了します。変更前にセーブと既存設定をバックアップしてください。
2. `C:\Games\Lillia` など短いパスを使用します。必要なら EXE だけでなく**ゲームフォルダー全体**を移動してください。深い階層では BepInEx 無効時もキャラクター読み込みが失敗し、同じファイルを短いパスに置くと成功しました。正確なパス長の上限は未確定です。
3. セットの**全内容**を `NoviceSuccubusLillia.exe` と同じ場所に展開します。圧縮ファイル内から起動したり、Data フォルダーに入れたり、EXE とローダーの間に余分なフォルダーを挟んだりしないでください。
4. 以下の配置と照合します。EXE と Data フォルダーはゲーム本体のもので、セットはローダー、ランタイム、プラグイン、設定を追加します。

```text
C:\Games\Lillia\
  NoviceSuccubusLillia.exe
  NoviceSuccubusLillia_Data\
  winhttp.dll
  doorstop_config.ini
  dotnet\
  BepInEx\
    core\
    plugins\FirstPersonTest.dll
    config\BepInEx.cfg
    config\local.lillia.firstpersontest.cfg
```

5. 普段のゲーム EXE を起動します。初回はネット接続で Unity 基礎ライブラリを取得し、`BepInEx/interop` を生成するため、数分かかる場合があります。待機中に複数のゲームを起動しないでください。ログ用コンソールが表示されないのは正常です。
6. ゲームプレイに入ると一人称が初期状態で有効です。ゲームを前面にして **F8** の視点切替、**F9** の髪の表示切替を確認します。プラグインログには `Loaded v0.1.28` が記録されます。読み込み成功だけで全機能の動作が確認できるわけではありません。

### プラグインの導入・更新（BepInEx 導入済み）

1. セーブして終了し、古い DLL と `BepInEx/config/local.lillia.firstpersontest.cfg` を `plugins` の外へバックアップします。
2. `BepInEx/plugins/FirstPersonTest.dll` を置き換えます。サブフォルダーも含めて一つだけにし、バックアップ DLL を残さないでください。既存ローダーと設定は保持します。
3. 単体プラグインの初回導入では一度起動して設定を生成し、終了します。生成直後の `ClipLimits` は空欄ですが、同梱セットには 4 項目が設定済みです。
4. DLL の更新だけでは新しい設定例は**自動追加されません**。`[EventView]` の既存 `ClipLimits` 一行に、同梱 README の 4 項目の例を統合し、自分の設定も残します。同じクリップ名は一度だけ記述し、値全体を一行に保ちます。今回の追加は `Fellatio_Female(Gsun)_Loop|3|2|2` です。
5. 保存してゲームを再起動してください。設定は起動時に読み込まれます。今回のセット改訂は設定と説明のみで、0.1.28 DLL は変更していません。

### トラブル対処

| 症状 | 最初に確認すること |
| --- | --- |
| 一人称にならない／F8 が反応しない | ゲームプレイに入り、ウィンドウを前面にします。フォルダー階層と DLL の重複を確認し、ローダー・プラグインログの読み込み結果やエラーを調べます。 |
| 初回起動が止まって見える | `BepInEx/LogOutput.log` でダウンロードや interop 生成が進んでいるか確認します。取得失敗なら具体的なエラーと接続を確認してから再試行し、起動を繰り返さないでください。 |
| `Character content could not be loaded` | Unity ログの `A local absolute bundle path is required` を探します。あれば終了してゲーム全体を短いパスへ移動します。画面の表示だけではパスが原因と断定できません。続く場合はログを保存してください。 |
| イベント視点の可動範囲が広い | `Event view: clip=...` の正確な名前、対応する ClipLimits、再起動の有無を確認します。大文字・小文字を区別し、未一致のクリップには共通範囲が適用されます。 |
| 髪や NPC が視界を遮る | F9 で髪を切り替え、遮られるイベントでは F8 で三人称に戻します。 |

ローダーログ：`BepInEx/LogOutput.log`。プラグインログ：`BepInEx/FirstPersonTest.log`。Unity ログ：`%USERPROFILE%\AppData\LocalLow\PaconeSoft\Novice Succubus Lillia\Player.log`。再起動前に必要なログを保存し、通常の導入手順としてセーブやキャッシュを削除しないでください。

一時停止は F8、アンインストールはゲーム終了後に `BepInEx/plugins/FirstPersonTest.dll` のみを削除します。他の MOD が使うローダーは残してください。旧版へ戻す場合はバックアップした DLL と設定を復元します。ダウンロードの照合には `SHA256SUMS.txt` を使えます。

Gsun クリップの制限（左右各 3°、上下各 2°）はゲーム内テストを通過し、実施者が確認しました。全クリップを網羅した検証を意味するものではありません。

**ゲーム 1.2 の動作確認（2026-10-23）：** GitHub Releases の公開済み v0.1.28 セットをダウンロードし、ゲーム 1.2 に導入しました。初回の初期化後、ユーザーから問題なく動作したとの報告がありました。このテストではプラグインの変更は不要でした。ユーザーによる動作報告であり、全シーン・アニメーション・新機能を網羅した検証ではありません。従来のゲーム 1.1 の検証記録も下記に残しています。
